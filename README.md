# 🛡️ ProxVault v4.0

> A powerful and professional desktop proxy suite built with Python.

---

## ✨ Features

- ✅ Check **HTTP, HTTPS, SOCKS4, SOCKS5** proxies
- ⚡ Speed & latency testing
- 🕵️ Anonymity detection — Elite / Anonymous / Transparent
- 🌍 Geolocation lookup per proxy
- 🏆 Smart proxy scoring system
- 📊 Export reports — CSV, JSON, HTML, PDF
- 🌙 Beautiful dark mode GUI (ttkbootstrap)
- 🔄 Multi-threaded proxy checking

---

## 📦 Requirements

pip install requests ttkbootstrap matplotlib pandas numpy tenacity pysocks reportlab

---

## 🚀 How to Run

python NewVersion.py

---

## 🗂️ Project Structure

ProxVault/
├── NewVersion.py        # Main application
├── proxy_cache.json     # Auto-generated cache
└── proxy_checker_config.ini  # Auto-generated config

---

## ⚠️ Notes

- 🔌 For SOCKS4/SOCKS5 support, make sure **PySocks** is installed
- 📄 For PDF reports, **ReportLab** is required
- 🌐 Internet connection is required for proxy checking
